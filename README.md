**Noot-Noot The Game** is a fast-paced and fun Python arcade game where you take control of the legendary penguin **Noot-Noot** and try to **dodge incoming obstacles** to get the highest score possible!  

Brace yourself for an icy adventure full of excitement, quick reflexes, and endless fun. ❄️  

---

## 🎮 How to Play  

Follow these simple steps to start your adventure:  

1. **Install Python**  
   If you haven’t already, download and install Python on your machine:  
   👉 [https://www.python.org/downloads/](https://www.python.org/downloads/)  

2. **Clone the Repository**  
   Clone this repository or download the ZIP file to your computer.  

   ```bash
   git clone https://github.com/your-username/Noot-Noot-The-Game.git
   cd Noot-Noot-The-Game

3. **Install Pygame:** 
    Open the command prompt or terminal and type the following command to install the necessary library for the game:

    ```
    pip install pygame
    ```

4. **Run the Game:** 
   Launch the game with:

    ```
    python main.py
    ```
